# SoC Design Journal

SoC 설계 과목을 수강하며 진행한 실습·과제 내용을 날짜별로 정리하는 학습 일지 레포입니다.

## 폴더 구조

```
soc-design-journal/
├── README.md              # 레포 소개
├── journal/
│   └── YYYY-MM-DD.md      # 날짜별 학습 로그
└── concepts/
    └── *.md                # 날짜에 얽매이지 않는 개념 정리
```

- `journal/YYYY-MM-DD.md`: 해당 날짜에 진행한 실습 내용, 명령어, 트러블슈팅 등을 정리한 로그.
- `concepts/*.md`: 특정 실습에 종속되지 않는 배경 개념(용어 정의, 이론) 정리.
