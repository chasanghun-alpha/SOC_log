# 2026-09-22

## 주제

VCS toggle coverage 측정 및 정제 (`alu_stage` 과제)

## 1. 기본 실행 흐름

toggle coverage를 켜고 리포트를 만드는 최소 흐름은 컴파일 1번 + urg 1번.

```bash
# 1) 컴파일 + 시뮬레이션 (컴파일 단계에서 -cm tgl로 커버리지 계측을 켠다)
vcs_queue --fsdb -full64 +v2k -debug_access+all -kdb -top tb_alu_stage \
    alu_stage.v tb_alu_stage.v \
    -cm tgl -cm_dir toggle.vdb \
    -o simv -R +CASE=baseline -l vcs.log

# 2) 리포트 생성 (VCS_HOME 등 환경변수를 먼저 잡아야 한다)
source /opt/eda/env/eda-config.sh
urg -full64 -dir toggle.vdb -metric tgl -format both \
    -report urgReport -log urg.log
```

- `-cm tgl`: 토글 커버리지를 계측 대상으로 지정
- `-cm_dir toggle.vdb`: 계측 결과를 저장할 DB 폴더
- `+CASE=<이름>`: 테스트벤치에 `$value$plusargs`로 전달되는 케이스 선택 인자
- 결과는 `urgReport/dashboard.html`에서 확인. `Total Coverage Summary`(인스턴스 기준)와 `Total Module Definition Coverage Summary`(모듈 정의 기준)는 다른 지표이며, 실제로 봐야 하는 값은 **인스턴스 기준**(위쪽 요약).

## 2. 여러 테스트 케이스 자동화

케이스(`baseline` / `latch` / `missing_or` / `carry` / `valid` / `signed`)별로 나뉜 폴더를 순서대로 실행하는 스크립트를 사용. 이전 `coverage/` 폴더가 남아 있으면 컴파일이 스킵되거나 꼬일 수 있으므로 재실행 전에 삭제 처리.

```bash
#!/usr/bin/env bash
set -e

RESULTS=()

run_case() {
    local dir="$1"
    cd "$dir"

    if [ -d coverage ]; then
        echo ">>> $dir: 기존 coverage 폴더 삭제"
        rm -rf coverage
    fi

    echo ">>> $dir: run_coverage.sh 실행"
    if bash run_coverage.sh; then
        RESULTS+=("$dir:PASS")
    else
        RESULTS+=("$dir:FAIL")
    fi

    cd ..
}

for d in 01_baseline 02_latch 03_missing_or 04_carry 05_valid 06_signed; do
    run_case "$d"
done

echo "===== 전체 결과 ====="
echo "${RESULTS[@]}"
```

주의: DUT(`alu_stage.v`)가 폴더마다 다르면(버그가 다르게 심어져 있으면) 이후 병합 단계에서 `Database mismatch` 경고가 남. 병합은 반드시 **같은 설계(design)**를 대상으로 한다는 전제가 있음.

## 3. 불필요한 신호 제외 (Elfile / Exclusion)

테스트벤치 내부용 변수(예: 케이스 식별 문자열 `case_name`)는 값이 한 번 고정되면 다시 안 바뀌므로 toggle이 0이 되어 전체 수치를 왜곡함. `-cm_hier`(컴파일 시점, `+tree` 문법)는 모듈/인스턴스 단위라 신호 하나만 정밀하게 빼기엔 맞지 않았고, 실제로 맞는 도구는 **Elfile(`.el`) 기반 Coverage Exclusion**. `.el` 문법을 직접 타이핑하지 않고 **Verdi Exclusion Manager**로 자동 생성하는 편이 안전.

절차:

1. `verdi_sub -full64 -cov -covdir toggle.vdb &` 로 Verdi 커버리지 뷰어 실행
2. `File → Open Database`로 `toggle.vdb` 폴더 열기
3. `Hierarchy` 탭에서 대상 모듈(`tb_alu_stage`) 클릭
4. `CovDetail` 창의 `Toggle` 탭에서 제외할 신호(`case_name`) 우클릭 → `Exclude`
5. `Add Exclude Annotation`으로 사유 기록 (예: "Test case identifier string, not DUT logic")
6. `Exclusion Manager` 탭에서 등록한 항목 선택 → `Exclusion → Save Exclusions for Selected Objects...`로 `.el` 파일 저장

생성된 `.el` 문법:

```
_instance { tb_alu_stage } { _toggle { case_name } }
```

리포트 생성 시 `-elfile`로 적용 (컴파일 재실행 불필요, 기존 `toggle.vdb` 재사용):

```bash
urg -full64 -dir toggle.vdb -metric tgl -format both \
    -elfile exclusion.el \
    -report urgReport -log urg.log
```

같은 `tb_alu_stage.v`를 쓰는 다른 케이스/폴더라면 `exclusion.el`을 그대로 복사해서 재사용 가능 (Verdi 작업 반복 불필요).

## 4. 여러 케이스 커버리지 병합

`urg`는 `-dir`을 여러 번 주면 여러 `toggle.vdb`를 자동 병합. 지켜야 할 두 가지:

- **절대경로 사용**: 병합 폴더로 `cd` 한 뒤 상대경로를 넘기면 `Warning-[URG-DNF] Directory not found` 발생. 스크립트 시작 시점에 `BASE_DIR="$(pwd)"`로 절대경로를 고정해둘 것.
- **DUT가 완전히 동일해야 함**: 병합 대상 케이스들의 DUT 구조(신호 개수·비트 폭)가 다르면 `Database mismatch for instance data` / `UCAPI-INSTANCEMISMATCH` 경고가 나고 해당 케이스는 병합에서 빠짐. 버그를 고친 DUT라면 재컴파일 후 새 `toggle.vdb`로 다시 병합해야 함.

```bash
#!/usr/bin/env bash
set -e

source /opt/eda/env/eda-config.sh
URG="$VCS_HOME/bin/urg"

DIRS=(01_baseline 02_latch 03_missing_or 04_carry 05_valid 06_signed)
BASE_DIR="$(pwd)"

URG_ARGS=()
for d in "${DIRS[@]}"; do
    VDB_PATH="$BASE_DIR/$d/coverage/toggle.vdb"
    if [ -d "$VDB_PATH" ]; then
        URG_ARGS+=(-dir "$VDB_PATH")
    else
        echo ">>> 경고: $VDB_PATH 없음."
    fi
done

mkdir -p merged_coverage
cd merged_coverage

"$URG" -full64 "${URG_ARGS[@]}" -metric tgl -format both \
    -elfile "$BASE_DIR/01_baseline/exclusion.el" \
    -report urgReport -log urg_merge.log
```

`-elfile`을 병합 시에도 넣어야 개별 리포트뿐 아니라 병합 리포트에도 제외가 반영됨.

## 5. 트러블슈팅

| 에러/증상 | 원인 | 해결 |
| --- | --- | --- |
| `Failed to obtain license` | VCS 라이선스 큐 획득 실패 | Icarus Verilog(`iverilog` + `vvp`)로 임시 대체 실행 |
| `Warning-[VCM-HFNM] No pattern match` | `-cm_hier` 설정 파일 문법을 `tree ...`로 썼으나 실제로는 `+tree ...`(앞에 `+`)가 맞는 문법 | `+tree top.dut.core3` 형태로 수정 |
| `Warning-[UCAPI-SNF] Shape Not Found` | 잘못된 exclude 문법(`disable_coverage -inst`)으로 컴파일해서 toggle coverage 자체가 수집 안 됨 | `-cm_hier` 옵션 없이 원래 `-cm tgl` 컴파일로 되돌리고, 신호 제외는 리포트 단계의 Elfile(`.el`)로 처리 |
| `Warning-[URG-DNF] Directory not found` | `cd` 이후 상대경로로 `-dir`을 넘겨 엉뚱한 위치를 찾음 | 스크립트 시작 시 `BASE_DIR="$(pwd)"`로 절대경로 고정 |
| `Please make sure VCS_HOME is set correctly` | `urg` 실행 전에 환경변수를 안 잡음 | `urg` 실행 전 `source /opt/eda/env/eda-config.sh` 먼저 실행 |
